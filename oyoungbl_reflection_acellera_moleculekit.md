# Reflection: acellera_moleculekit

## Inactivity patterns
This project was never inactive for long. Commits arrive in every year from 2019 to 2025, ranging from about 110 to 405 a year, with a peak in 2022 (405) and a stable level of roughly 140 to 190 since. The longest zero-commit stretch is a single month (Aug 2020), and there are no gaps of three months or more, so the project is steady rather than gappy.

## Was the longest gap easy or hard to interpret?
Easy, because it is barely a gap. The last commits before it (July 2020) are small bug fixes, and the first ones after it (Sep 2020) update dependencies for a new OpenBabel release and move the Docker setup from HTMD into moleculekit.

## Likely reasons for inactivity or recovery
A one-month pause in a small, mostly single-maintainer scientific package is normal. No recovery reason needed.

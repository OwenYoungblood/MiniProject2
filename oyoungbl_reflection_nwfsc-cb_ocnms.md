# Reflection: nwfsc-cb_ocnms

**Project facts:** 532 commits, 13 authors, 2015-11 to 2025-08. Pattern: irregular. Longest gap: 2023-03 to 2024-06 (16 months). Gaps of 3+ months: 7. Status: Active.

## Inactivity patterns
This is a bursty project. There are 112 commits in 2017, and 152 in 2021, but only 3 in 2016, 11 in 2023 and 25 in 2024. Seven gaps of three months or more make the timeline irregular. The repository looks like a research data and analysis project, where activity clusters around data updates and reporting rather than a steady development process.

## Was the longest gap easy or hard to interpret?
Hard. GitHub has almost nothing to go on: only 2 pull requests have ever been opened and there are no issues, so the work happens through direct commits and the evidence is limited to commit messages. Before the gap the commits are about the 2022 data (black rockfish, kelp plots, "update 2022 data", Jan 2023). After it, the first commit is "update to 2023 data" (2024-07-22).

## Likely reasons for inactivity or recovery
My hypothesis is a yearly data-update cycle: the next year of data was not processed until mid 2024, so the repository sat idle in between. This is a guess from commit messages, and I did not check whether other years show the same pattern. Recovery was by the same two people who were active before (both post-gap authors were returning), who added the annual update file and new plots in Oct 2024, one of which was prepared for a talk. PR #2, the flagstone branch merge (2024-10-23), is the only pull request in that period.

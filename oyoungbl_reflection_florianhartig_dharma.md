# Reflection: florianhartig_dharma

**Project facts:** 1,281 commits, 45 authors, 2015-02 to 2025-10. Pattern: irregular. Longest gap: 2015-03 to 2016-05 (15 months). Gaps of 3+ months: 3. Status: Active.

## Inactivity patterns
Activity comes in waves rather than a steady stream: 149 commits in 2016, a dip in 2017 (45), a rise to 325 in 2021, another dip (32 in 2023) and a recovery to 130 in 2024. The three long gaps and these swings make the trajectory irregular, though the project has not stopped since 2016 and was still receiving commits in Oct 2025.

## Was the longest gap easy or hard to interpret?
Easy, and it is mostly an artifact. Before the gap the repository holds only two commits from 2015-02-10 ("Initial commit" and "checkin"). The R package itself was created on 2016-06-13 ("package created", "package functions added", "help and vignette update"). GitHub agrees: there are no pull requests in that period, and the first issues (#1 to #4) appear in Jun to Sep 2016, after the package existed.

## Likely reasons for inactivity or recovery
The repository was a placeholder before development started, so this is not abandonment. Recovery was the same person starting the real work: Florian Hartig is the only author after the gap. The later dips probably reflect release cycles and the maintainer's other commitments, but I did not investigate those.

# Reflection: pyscf_pyscf

**Project facts:** 14,445 commits, 356 authors, 2014-05 to 2025-11. Pattern: steady. Longest gap: 2014-09 (1 month). Gaps of 3+ months: 0. Status: Active.

## Inactivity patterns
Pyscf grew quickly, from 133 commits in 2014 to 977 in 2015 and a peak of 2,512 in 2017, then settled at about 900 to 1,500 a year. The 2025 count in my data (611) is lower, but the WoC data ends in Nov 2025, and GitHub shows commits as late as Sep 2026, so I would not read that as a decline. The project has no gap longer than a single month.

## Was the longest gap easy or hard to interpret?
Easy. The gap (Sep 2014) falls between a flurry of module additions in July and August 2014 by the lead developer and a "version 0.5" update on 2014-10-02. That looks like a short break between development bursts at the very start of the project.

## Likely reasons for inactivity or recovery
No real inactivity exists. The pause sits in the first months of a project developed by one person, who then continued with a release and build changes (CMake, libcint, libxc). The latest commits (Oct to Nov 2025) are new features such as an interface to gpu4pyscf, plus bug fixes, so it is clearly still active.
